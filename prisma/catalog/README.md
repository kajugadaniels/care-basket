# Curated U.S. catalog

This directory's derivative catalog data is offered under [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/). Individual source contents are covered by [DbCL 1.0](https://opendatacommons.org/licenses/dbcl/1-0/). Attribute Open Food Facts and Open Prices contributors, and CareBasket for manually curated demo data. Application code has a separate licensing scope.

The committed dataset contains 50 reviewed demo products with approved demo prices. Child suitability remains unapproved (`isChildSuitable: false`); do not change these flags without a separate safety review. Category placeholders cover missing images. The seed still refuses an empty dataset, and the presence of this file does not prove that a database has been seeded. Additional products require legitimate discovery and human review; household and personal-care coverage may need clearly labelled manual demo products.

See [the Step 6 guide](../../docs/step-6-catalog.md) for discovery, the complete record format, review, image handling, and manual seed commands. Reports are not approved seed input. All prices are fictional, explicitly approved prices for CareBasket Demo Market; historical observations never feed checkout directly.
